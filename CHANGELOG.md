# Changelog

## [0.1.2] - 2026-11-17

### Fixed
- A left swipe could pass the app-active check while the app was resigning active (its direction value
  matched the synthetic-release marker). The synthetic release now uses an explicit flag.
- Press state and crown deltas are no longer updated by packets that take the lock after the app resigned
  active.
- A press could be released twice: once by the watchdog or on resign, then again by the watch's real
  release. The bridge now ignores a release when no press is active.
- Documentation no longer claims the native backgrounding path is unit-tested.

## [0.1.1] - 2026-11-17

Fixes from an independent code review.

### Changed
- The Embed Watch Content phase is added with Unity's `AddCopyFilesBuildPhaseBeforeTargetPostprocess`
  instead of a text edit of `project.pbxproj`.
- Build-step tests run against an Xcode project generated by Unity; idempotency is checked by counting
  phases, files, dependencies and framework links after a second run.
- Native bridge surface is internal; unused exports and event fields removed (event struct is 2 bytes).
- Documentation moved to `Documentation~` so it is not imported into projects.

### Fixed
- `PressReleased` now fires when the app is backgrounded during a press (and on any IsPressed true → false edge).
- Race between the app-active check and the event buffer.
- Editor scripts that use the iOS Xcode API are guarded consistently, so projects without iOS Build Support compile.
- Inaccurate comments and README numbers.

### Added
- Tests asserting no GC allocation in the per-frame input pump.

## [0.1.0] - 2026-11-17

First release.

### Added
- Automatic watchOS app target in Unity iOS builds (`PostProcessBuild`): sources, build settings, embed phase,
  WatchConnectivity link, app icon, generated Swift config, signing inherited from Player Settings.
- Project Settings › Watch Input panel with live validation and a non-blocking pre-build check.
- Watch app: tap, press-and-hold, four-way swipe, Digital Crown (unbounded, detent haptics), status text.
- Haptics from Unity to the watch (9 types).
- `WatchInput.Watch` static API with per-frame state and events, driven from the PlayerLoop.
- Editor / non-iOS simulation with mouse, touch and keyboard (Input System and legacy Input Manager).
- Timestamped binary protocol (v2); stale and background input is dropped.
- Basic Demo sample.
- 39 EditMode tests.
